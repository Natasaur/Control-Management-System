# Crear una rama desde develop
git checkout develop
git pull origin develop
git checkout -b nombre-de-tu-rama

# Trabajar, agregar y commitear
git add .
git commit -m "Resumen de lo que se implementó"

# Subir tu rama
git push origin nombre-de-tu-rama

# Mantener tu rama al día con develop
git checkout develop
git pull origin develop
git checkout nombre-de-tu-rama
git rebase develop   # o git merge develop

# Subir cambios actualizados
git push origin nombre-de-tu-rama

# Finalmente, hacer el Pull Request en GitHub
Cuándo usar rebase vs merge
✅ Rebase:

Deja tu historial más limpio.

“Reescribe” tu rama para poner tus commits encima de develop.

✅ Merge:

Más seguro si no dominas rebase.

Genera un commit de merge → historial un poco más sucio, pero sin reescribir nada.
